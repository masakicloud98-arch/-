# SHIRO EC トップページ モックアップ

北海道砂川発のコスメティックブランド SHIRO のオンラインストア（https://shiro-shiro.jp/ec/ ）を題材に、
**現行サイトのトンマナに準拠**しつつ、CVR 最大化の施策を織り込んだトップページのデザインモックです。

**`index.html` をブラウザで開くだけで動作します**（外部依存なし・単一ファイル）。

## トンマナ — 現行サイトからの抽出

現行トップページのキャプチャを基に、以下のデザイン言語を踏襲しています。

| 要素 | 現行サイトの特徴 → 本モックでの再現 |
| --- | --- |
| 配色 | ダークネイビーの文字・ボタン、フッターは濃紺ベタ（`#000030`）、背景は純白、ベージュの帯 |
| タイポグラフィ | 全面ゴシック体。見出しは「英字大文字レタースペース + 小さな和文サブ」（NEW LINEUP／新製品 形式） |
| ヒーロー | フルブリードのビジュアルに巨大な白い SHIRO ロゴタイプを重ねる。ヘッダーは透過白 → スクロールで白背景・紺 |
| 商品カード | スタジオ調のライトグレー背景、商品名 +「N,NNN円（税込）」+ グレーの効能ノート。過度な装飾なし |
| ボタン | 「もっと見る」の細枠ゴーストボタンのみ |
| セクション構成 | NEW LINEUP → SEASONAL PICK UP → MONTHLY RANKING → NEWS → SERVICE → ABOUT SHIRO → INFORMATION → 濃紺フッター |

写真素材の代わりに、SVG フィルタ（feTurbulence）とグラデーションで写真調の質感を、インライン SVG で商品シルエットを構成しています。

## CVR 最適化の設計（トンマナを崩さない範囲で追加）

1. **購入不安の除去** — 濃紺の告知バー（送料無料ライン等のローテーション）+ 静かな一行 USP 帯
2. **迷わせない導線** — ヒーロー直下にベージュのクイックエントリー帯（ベストセラー／ギフト／新製品）+ カテゴリ行
3. **ソーシャルプルーフ** — MONTHLY RANKING の No. 表示、控えめな ★ 評価 + レビュー件数
4. **緊急性・希少性** — 夏季限定・NEW・再入荷バッジ。完売品は「再入荷通知」でリード化
5. **摩擦低減** — カードホバーで出現するクイック「カートに入れる」（トースト + カートバッジ連動）、お気に入り
6. **パーソナライズ** — 「香りから選ぶ」導線 + SCENT FINDER（香り診断）でサンプルセットへ誘導
7. **LTV** — 会員登録 300pt・誕生月クーポン・先行案内の MEMBERSHIP セクション
8. **モバイル最適化** — レスポンシブ + 下部固定ナビ（ホーム／検索／お気に入り／カート）

## 実装メモ

- 単一 HTML（CSS/JS/SVG すべてインライン）、外部リクエストゼロ
- バニラ JS のみ：ヒーロースライダー、告知ローテーション、スクロール出現、ランキングタブ、カート／お気に入りのマイクロインタラクション
- 本モックは学習・提案用のデザインモックであり、SHIRO 公式とは無関係です
