# SHIRO EC トップページ モックアップ

北海道砂川発のコスメティックブランド SHIRO のオンラインストア（https://shiro-shiro.jp/ec/ ）を題材に、
ブランドの世界観・価値観の表現と CVR 最大化を両立させたトップページのデザインモックです。

**`index.html` をブラウザで開くだけで動作します**（外部依存なし・単一ファイル）。

## デザインコンセプト — 「シロらしさ」の翻訳

| ブランドの価値観 | デザインへの落とし込み |
| --- | --- |
| 余白と静けさ（ミニマルな白の世界観） | 白〜生成りの3階調のみの背景、細い罫線、明朝体見出し、広い字間・行間 |
| 「自然の恵みを、あますことなく」 | がごめ昆布・酒かす・ゆずの素材セクション、砂川のブランドストーリー |
| 香りが主役のブランド | 「香りから選ぶ」をファーストビュー直下に配置（サボン/ホワイトリリー/ホワイトティー…） |
| サステナビリティ・エシカル | エシカル割（簡易梱包で3%OFF）の常設バンド、告知バーでの訴求 |
| 「世の中をしあわせにする」 | コピーライティング全体を「しあわせ」を軸にトーン統一 |

装飾色は CTA の深緑（針葉樹）と限定・ギフトの金のみ。写真素材の代わりに、香りごとの淡いグラデーション＋インライン SVG のプロダクトシルエットで世界観を構成しています。

## CVR 最適化の設計

1. **購入不安の除去** — 告知バー＋USPストリップ（送料無料ライン / 翌日配送 / ラッピング無料 / ポイント還元）を常時視界に
2. **迷わせない導線** — 「香りから選ぶ」→「ランキング」の2段構えで初回訪問者の意思決定コストを最小化
3. **ソーシャルプルーフ** — 星評価＋レビュー件数、ランキング No. 表示、UGC（#SHIROのある暮らし）
4. **緊急性・希少性** — 夏季限定バッジ、再入荷バッジ、完売品には「再入荷通知」ボタン（機会損失をリードに転換）
5. **回遊の摩擦低減** — 一覧からのクイックカート追加（トースト＋バッジアニメーション）、お気に入り、カテゴリタブ切替
6. **パーソナライズ** — 香り診断バナー（「試せない」というEC最大の障壁をサンプルセット導線で解消）
7. **LTV 施策** — 会員登録300pt・誕生月クーポン・再入荷先行案内のメンバーシップセクション
8. **モバイル最適化** — レスポンシブ＋下部固定ナビ（ホーム/検索/お気に入り/カート）

## 実装メモ

- 単一 HTML（CSS/JS/SVG すべてインライン）、外部リクエストゼロ
- フォントはシステムフォント（游明朝/ヒラギノ明朝 × ゴシック体）で SHIRO のタイポグラフィを再現
- バニラ JS のみ：ヒーロースライダー、告知ローテーション、スクロール出現（IntersectionObserver）、タブフィルタ、カート/お気に入りのマイクロインタラクション
- 本モックは学習・提案用のデザインモックであり、SHIRO 公式とは無関係です
